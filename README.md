# Robotics Study

로보틱스의 기초 이론부터 임베디드 시스템, ROS 2 기반 로봇 소프트웨어 개발까지 학습한 내용과 실습 코드를 정리한 리포지토리입니다.

## 학습 목표

- 로봇의 Perception, Planning, Control 파이프라인 이해
- ESP32 기반 임베디드 시스템 및 하드웨어 제어
- 센서 데이터 수집 및 통신 프로토콜 이해
- ROS 2 기반 로봇 소프트웨어 개발
- 시뮬레이션 및 로봇 내비게이션 구현
